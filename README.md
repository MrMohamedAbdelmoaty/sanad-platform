# منصة سند — Sanad Platform

نسخة كاملة (Next.js 14) مبنية بنفس تصميم منصة «واعدون» البصرية، بهوية واسم ومحتوى جديدين بالكامل.

> **الاسم الجديد:** سند · **الوصف:** منصة البرامج المباشرة والدورات المسجّلة ومتابعة الأبناء
> **الخط:** IBM Plex Sans Arabic (محلي داخل المشروع — لا يعتمد على الإنترنت)
> **الهوية اللونية:** مستخرجة من التصميم الأصلي: `#011D35` كحلي · `#2EC2EB` سماوي · `#CDA349` ذهبي · `#F7FAFC` خلفية

---

## التشغيل السريع

```bash
cd sanad
npm install
npm run dev        # http://localhost:3000
npm run build      # بناء إنتاجي (37 صفحة ثابتة)
npm run start
```

## الصفحات

| المسار | الوصف |
|---|---|
| `/` | الرئيسية: شريط تنقيه، هيرو + بطاقة البرنامج المميز، البرامج المباشرة، الورش المباشرة، الورش المسجلة، الدورات المسجلة، الباقات، بانر CTA، فوتر |

## تغيير المحتوى

كل النصوص والأسماء والأسعار في **`lib/data.ts`** فقط:

- `brand` — اسم المنصة، الوصف، الهاتف/واتساب
- `hero` + `flagship` — الهيرو والبرنامج المميز
- `livePrograms` — البرامج المباشرة (هِمّة، دُنَا، صحبة)
- `liveWorkshops` — الورش المباشرة
- `recordedWorkshops` و `courses` — المحتوى المسجل
- `bundles` — الباقات
- `guideSteps` و `faqs` — دليل الأسرة
- `nav` — روابط الهيدر

> الأغلفة: أي عنصر له `poster` يعرض بوستر تصميمي بالهوية (بدل الصورة) إذا لم يوجد ملف صورة.
> لإظهار صورة: ضع الملف في `public/images/` واكتب مساره في `cover`، واحذف `poster`.

## التوصيل بـ Supabase

1. أنشئ مشروعًا في Supabase وشغّل `supabase/schema.sql` في SQL Editor.
2. انسخ `.env.example` إلى `.env.local` واملأ:
   ```
   NEXT_PUBLIC_SUPABASE_URL=https://xxxx.supabase.co
   NEXT_PUBLIC_SUPABASE_ANON_KEY=xxxx
   ```
3. استخدم `getSupabase()` من `lib/supabase.ts`.
   الجاهز في المخطط: `parents` / `children` / `programs` / `units` / `lessons` / `enrollments` / `session_reports` / `lesson_progress` / `bundles` — مع سياسات RLS كل ولي أمر يرى بياناته فقط.

## ما الذي تغيّر عن النسخة الأصلية؟

**الأسماء الجديدة بالكامل:**

| الأصل (واعدون) | الجديد (سند) |
|---|---|
| منصة واعدون | منصة سند |
| الجلسة التربوية | مجلس السند |
| قادر | هِمّة |
| رائدة | دُنَا |
| برنامج صحبة | صحبة |
| أنوثتي.. فخر أم عبء؟ | هويتي.. فخر أم عبء؟ |
| ملتقى واعدون الصيفي | ملتقى سند الصيفي |
| مؤتمر المراهقة المشرقة | توازن: رحلة إلى فهم الذات |
| كبرت وتغيرت | مسؤوليتي عنوان رجولتي |
| بصير | توازن (مسار جديد لأ. سعيد العامري) |
| بناء عادات النجاح | بناء عادات الثقة |
| أثر الفكرة | أثر الفكرة (بنفس المعنى، مدرّبة جديدة) |
| بناء تقدير الذات | تقدير الذات: رحلتك نحو صورة صحية |
| التخطيط: رحلة إلى السعادة | خطتي: رحلة إلى السعادة |
| مفاتيح التفكير العشرون | مفاتيح التفكير العشرون |
| أساسيات الفريلانس للمراهقين | أساسيات العمل الحر للمراهقين |
| البوصلة المهنية | بوصلة المستقبل المهني |
| دماغ الفريلانسر | ★ (أُعيد تصميمه في باقة الخبراء) |
| إعادة تشغيل الدماغ | إعادة تشغيل الدماغ «إدمان الجوال والألعاب» |
| ورشة رجولة | صحبة اختيار — ورشة الصحبة والاختيار |
| عبير الفطرة | لمسة فطرة |
| باقة الخبراء / ماهر | باقة الخبراء / باقة الأسرة |
| أ. أحمد سعيد | أ. سعيد العامري |
| نشوى الفولي | د. لمياء الخالدي |

**المدربون** كلهم أسماء جديدة، **الهاتف** تمهيدي placeholder في `lib/data.ts`، والصور أغلفة مولّدة جديدة.

## النشر على Render

المشروع جاهز للنشر مباشرة:

- `render.yaml` — Blueprint يضبط كل شيء تلقائيًا (Render → New → Blueprint).
- `Dockerfile` + `.dockerignore` — للنشر بـ Runtime = Docker.
- `app/api/health/route.ts` — نقطة فحص صحة على `/api/health`.
- `start` يقرأ `PORT` تلقائيًا: `next start -H 0.0.0.0 -p ${PORT:-3000}`.

📘 **الدليل الكامل (GitHub + Render):** [`docs/DEPLOY_GITHUB_RENDER.md`](docs/DEPLOY_GITHUB_RENDER.md)

### تنبيه

هذه إعادة بناء كاملة للتصميم الأصلي بهوية جديدة — النصوص التربوية والصور المأخوذة من المنصة الأصلية مأخوذة منها نسخيًا أو معدّلة، وتستعمل لغرض استبدالها في المنصة الجديدة. تحقّق من رخصة استخدام المحتوى الأصلي إذا أردت النشر على نطاق واسع، أو استبدل محتوى `lib/data.ts` بمحتوى فريقك.
